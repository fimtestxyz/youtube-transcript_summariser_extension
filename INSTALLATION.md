# Installation

## Prerequisites
- Node.js 18+
- npm
- Chrome 115+ with Manifest V3 support

## Setup
- In project root, install dependencies:
  - `npm install`
- Build the extension:
  - `npm run build`

## Load in Chrome
- Open `chrome://extensions`
- Enable `Developer mode`
- Click `Load unpacked`
- Select the `dist` folder generated by the build

## Verify
- Open a YouTube watch page: `https://www.youtube.com/watch?v=bXKG_7q9p7c`
- When the page issues a JSON `/api/timedtext?v=...` request, a badge appears: `Transcript captured`
- Press `Cmd+I` to open the transcript panel with full transcript displayed
- Use the search box to filter transcript lines; click "Copy filtered results" to copy to clipboard
- Click any transcript line to seek the player to that timestamp
- Press `Cmd+B` to download the joined transcript text as `<video_title_slug>.txt`
- Use the popup to customize shortcuts (default: `Cmd+I` for panel, `Cmd+B` for text download)
- Downloaded files are named after the video title (e.g., `how-to-make-coffee.json` or `how-to-make-coffee.txt`)
- Navigate to another video; the badge resets and reappears upon detection

## Development
- Run `npm run dev` to watch and rebuild on changes
- Reload the unpacked extension after each build
- Adjust the shortcut via the popup; the content script applies changes live
