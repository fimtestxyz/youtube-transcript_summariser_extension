🔍 Ollama API Diagnostic Tool

Use this tool to test your Ollama installation and find the correct API endpoint.

Configuration

Test 1: Check Ollama Server

This checks if Ollama is running and accessible.

Test 2: List Models

This lists all installed models on your Ollama server.

Test 3: Test /api/chat Endpoint

This tests the native Ollama chat endpoint (recommended for v0.16.1+).

Test 4: Test /api/generate Endpoint

This tests the native Ollama generate endpoint (legacy).

Test 5: Test OpenAI-Compatible Endpoint

This tests the OpenAI-compatible endpoint (if available).

Quick Commands

Run these in your terminal to diagnose issues:

Check if Ollama is running:

curl http://localhost:11434/api/tags

List installed models:

ollama list

Install llama2 model:

ollama pull llama2

Start Ollama server:

ollama serve

Test chat endpoint:

curl http://localhost:11434/api/chat -d '{ "model": "llama2", "messages": [{"role": "user", "content": "Hi"}], "stream": false }'
